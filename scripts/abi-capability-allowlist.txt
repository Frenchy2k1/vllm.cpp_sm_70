# C-ABI capability allowlist — the EMBEDDER-UNREACHABLE tracker for
# scripts/check-surface-coverage.py (axis 2, capability reachability).
#
# The developer-directed invariant (2026-08-07, the ONE SURFACE directive / row
# ARCH-ONE-SURFACE): every capability advertised on docs/FEATURES.md's C-ABI capability
# table must EITHER name a C-ABI entry point that actually exists in include/vllm.h
# (a `reachable` row — the checker verifies each named symbol is declared), OR be an
# `embedder-unreachable` row backed by an entry here that names the fold row growing the
# ABI for it. This makes "the flat C ABI is the ONE way an embedder reaches a capability"
# a checked property, not a hope: an aspirational ABI claim (a `reachable` row whose
# symbol is not in vllm.h) reds, and a capability that is CLI/server-only but not tracked
# reds too.
#
# Each line matches ONE `embedder-unreachable` row of the abi-capability-table in
# docs/FEATURES.md by its normalized capability label (col 1, lowercased, spaces
# collapsed). Removing a line here — after the capability gains a C-ABI entry point and
# its FEATURES row flips to `reachable` — is the enforcement gate closing. A stale entry
# (no matching embedder-unreachable row) reds.
#
# Format: `<normalized capability label> | fold=<ROW-ID> | <reason: what exists, what the ABI lacks, fold order>`.
