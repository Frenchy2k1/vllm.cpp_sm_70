# CUDA keep-quant GGUF k-quant GEMM — `KERNEL-QUANT-CIQ-GEMM-CUDA`

The kCUDA provider for `OpId::kMatmulBTQuant`: the FIRST CUDA keep-quant GEMM for
any GGUF k-quant. Runs the DeepSeek-V4 routed-expert / MLA GEMMs on the GPU with
the weights kept COMPRESSED in the unified pool (no bf16 expansion, which would
OOM the 119 GiB pool at ~316 GiB), the way vLLM / llama.cpp / ds4 do — quantize
the activation tile to Q8_K on-GPU, then integer-dot it against the compressed
weight blocks (dequant-in-kernel via the block scales / codebook).

Owner claim: `CLAIM-CUDA-KEEPQUANT-GEMM`. Row: `KERNEL-QUANT-CIQ-GEMM-CUDA`
(kernel-matrix). Extends the CPU keep-quant `KERNEL-QUANT-CIQ-IQUANT` /
`QUANT-GGUF-CIQ-GEMM` onto the GPU; see also [DeepSeek-V4 §W8](deepseek-v4-flash.md).
