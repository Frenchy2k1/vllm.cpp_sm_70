## What was implemented (per the W4 W5-plan)

1. **Multi-shard GGUF reader** (loader-local, NO reader rewrite, NO merge):
   `LagunaGgufCtx` (`laguna_weights.cpp`) opens all shards, scans every shard's
   tensor table into a name→{owning `GgufFile`, `&info`} map, and routes each of
   the 814 tensors to the shard that holds it (shard-1 = header/KV only; shards 2/3
   carry the tensors). A keep-quant mmap borrow refcounts the RIGHT shard's mapping.
   `examples/laguna_gen` derives the sibling shard paths from `split.count` (a U16
   KV — the loader's `KvInt` handles U8/16/32/64).
2. **Params-from-KV** (`LagunaParamsFromGguf`): parses the `laguna.*` set — the
   per-layer `attention.head_count` ARRAY (48 global / 72 sliding → `layer_types`
   by min-head-count), dual-rope (`rope.freq_base` 500000 / `freq_base_swa` 10000,
   `dimension_count` 64 / `_swa` 128, `scaling.{type=yarn,factor=32,
   original_context_length=8192,yarn_attn_factor=1.0,beta_fast=32,beta_slow=1}`),
   MoE (`expert_count` 256, `expert_used_count` 10, `expert_feed_forward_length`
   1024, `expert_weights_scale` 2.5, `expert_gating_func` 2=sigmoid,
   `leading_dense_block_count` 1). Mirrors `DeepseekV4ParamsFromGguf`.
3. **Keep-quant tower** (`LoadLagunaFromGgufShards`): mirrors ds4 `V4GgufCtx`
   `Mw`/`Sew`/`Vec` — the attn q/k/v/o/gate (Q8_0), dense-L0 ffn (Q8_0),
   shared experts (Q8_0), routed `ffn_{gate,up}_exps` (Q4_K) / `ffn_down_exps`
   (Q5_K), and `output`/lm_head (Q8_0) stay block-COMPRESSED via
   `OwnGgufQuantBlocks`; `token_embd` (gather), `output_norm`, per-layer norms,
   `ffn_gate_inp` router, `exp_probs_b.bias`, `attn_{q,k}_norm` dequant to f32.
   Reuses the LANDED Q4_K/Q5_K/Q6_K/Q8_0 decode — **ZERO new decode kernel**.
4. **`LagunaForwardGguf`** (`laguna.cpp`): a COPY of the unit-gated f32
   `LagunaModel::Forward` composition with the ~9 GEMM sites swapped to keep-quant
